# Samsung Supply Chain & Logistics Analysis – Power BI

## Project Overview

An interactive Power BI dashboard designed to analyze supply chain and logistics performance across suppliers, manufacturers, shipments, customers, inventory, revenue, costs, profit, and delivery delays.

## Tools Used

- Power BI
- Power Query
- DAX
- CSV/Excel

## Dashboard Analysis

The dashboard provides analysis of:

- Supplier performance
- Manufacturer information
- Shipment quantity and delays
- Customer revenue contribution
- Inventory value by product
- Average supplier lead time
- Revenue, sales cost and profit
- Supply chain and logistics KPIs

## Key KPIs

- Total Revenue
- Total Sales Cost
- Gross Revenue
- Total Profit
- Order Quantity
- Inventory Value
- Total Shipment Quantity
- Total Delivered Quantity
- Shipment Delay
- Average Lead Time

The dataset was used from a YouTube Power BI tutorial for learning and practice purposes. The Power BI dashboard, analysis, visualizations, and report design were created by me.
